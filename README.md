# Arbetsmiljöplan App

Digital arbetsmiljöplan för byggprojekt – risker, skyddsåtgärder och export.

## Funktioner

- Projektinformation
- Kontrollmoment med status 1–2–3
- Spara i webbläsaren
- Export: PDF, Word, text

## Kör lokalt

```bash
npm install
npm run dev
```
